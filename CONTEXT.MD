# Project Context

(student, faculty, admin) sharing one MongoDB-backed service layer. See the
[repo root README](./README.md) for the full overview, tech stack, and current status,
and [PlacePrep-Vibe-Coding-Docs.md](./PlacePrep-Vibe-Coding-Docs.md) for the original
product/technical/schema planning notes this build was based on.

This file exists as a short entry point for anyone (or any AI coding tool) opening the
repo cold — start here, then README, then the doc above for depth.
